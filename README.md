Projeto Boi de Parintins – Sistema Automatizado com Arduino

Descrição
Projeto técnico desenvolvido como Trabalho de Conclusão de Curso Técnico, com foco em automação, integração de hardware e software e aplicação prática de lógica de programação.

O sistema simula um produto interativo inspirado no Festival de Parintins, realizando movimentos automatizados sincronizados com reprodução de áudio.

Funcionalidades
- Controle de motor de passo para movimentação automatizada
- Integração com módulo MP3 para reprodução de áudio
- Execução sincronizada de movimentos e som
- Estrutura física desenvolvida com impressão 3D

Tecnologias Utilizadas
- Arduino
- Linguagem C/C++
- Motor de passo
- Módulo MP3
- Impressão 3D

Objetivo do Projeto
Aplicar conceitos de lógica de programação, eletrônica e automação em um projeto prático, simulando o desenvolvimento de um sistema interativo real.
